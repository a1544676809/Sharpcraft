## 约定

1. 本目录只写**稳定的阶段划分与验收标准**；当前进度、阻塞、下一步动作属于 `docs/STATE.md`。
2. 里程碑的进出口条件必须可观测（命令 + 数值/图像），不得写成"完成度 80%"这类无法判定的描述。
3. 新增或调整里程碑属于范围变更，需要项目所有者确认并同步本目录与 `docs/STATE.md`。
4. 单个里程碑的具体任务仍进 `docs/traceability.md`（一行一个任务，含规格/测试/代码三列）。
