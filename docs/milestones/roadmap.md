# 里程碑规划（Roadmap）

本文件回答"整体任务拆成哪些里程碑、每个的出口条件是什么、现在在哪"。**易变状态不写在这里**（那是 `docs/STATE.md` 的职责），这里只写稳定的阶段划分与验收标准。

## 划分原则

里程碑按**可交付能力的闭环**切分，而不是按代码分层。每个里程碑必须满足：

1. 有可执行证据（命令 + 观测到的数值/图像），不靠"看起来做了"；
2. 完成后能独立回答"现在能做什么"，且不依赖下一个里程碑；
3. 涉及原则 3、7、8 的部分优先——它们是宪章的一等约束。

## M1 —— 基础逻辑地基（已完成）

出口条件：Common 地基与工程防线就位，能连上真实服务器。

| 内容 | 证据 |
| --- | --- |
| 宪章、文档体系、边界规则、架构门禁 | 18 项门禁断言全绿 |
| 标识符、随机数（LCG/xoroshiro，向量回放）、坐标、注册表顺序、方块状态 id | T-005…T-011 |
| 协议原语、握手/状态、登录加密、会话、play 入口 | T-012…T-017、T-019、T-021 |
| 认证链路（设备码端到端） | T-017、T-020 |
| 真实服务器验证 | `probe` / `play mcf.ddger.top` 到 play 阶段 |

## M2 —— 世界数据闭环（已完成）

出口条件：**能画出自己收到的世界**。

| 内容 | 证据 |
| --- | --- |
| NBT 读写（两种根、深度与长度上限） | T-024 |
| `level_chunk_with_light` 解析（段容器/高度图/光照 nibble）→ `ClientWorld` | T-025 |
| 真实会话校验区块数据 | 9/9 区块、275,141 非空气方块、97 个光照数组 |
| WGPU 最小管线（窗口 + 清屏 + 方块面批次） | T-026、T-027 |
| 真实世界出图 | 3×3 区块岛屿，275,142 方块 |
| 零分配改造、光照着色、背面剔除、贪婪合并、性能基线 | T-028…T-031 |

## M3 —— 资产管线 + 启动器闭环（进行中）

出口条件：**用一条命令，从用户本地 jar 走到带纹理的窗口画面**。

| 序 | 任务 | 状态 |
| --- | --- | --- |
| 1 | 里程碑规划与资产清单（本文件 + `docs/analysis/assets/jar-entry-map.md`） | 完成 |
| 2 | 资产模块设计文档 `docs/modules/assets.md` | 待评审 |
| 3 | T-032 版本清单解析 + jar SHA-1 校验 | 待开始 |
| 4 | T-033 资产打包器：白名单 → 单文件 pack（zip + manifest、原子、幂等、zip-slip 防护） | 待开始 |
| 5 | T-034 资源解析层：`IAssetSource`（pack 读取器 + 官方 objects 只读挂载）+ 覆盖顺序 | 待开始 |
| 6 | T-035 启动器承接：`assets` / `launch` 子命令 | 待开始 |
| 7 | T-036 纹理接入渲染（图集、UV、采样器、着色器采样） | 待开始 |

出口验收：

- `launcher assets --jar <path>` 完成校验与打包，产出单个 pack 并打印报告；
- `launcher window <address>` 显示带纹理的世界（截图存档）；
- 仓库内不出现任何资产，`git status` 干净；
- 测试覆盖：合成 jar 全链路、篡改场景、幂等、zip-slip、成对 `.mcmeta`、pack 读回一致；
- 音频走官方索引只读挂载，缺失时报错可诊断。

## M4 —— 交互与动态世界（未开始）

出口条件：**能操作，世界会变**。

- 输入系统（键盘/鼠标/焦点）、正式帧循环（时间步进而非"呈现 N 帧"）
- 玩家移动与相机控制、碰撞与重力（行为对齐原版量级）
- `block_update` / `section_blocks_update` → 局部重网格（走池化路径）
- 出口验收：能走进一个方块、挖掉一个方块并看到地形变化

## M5 —— 协议深化（未开始）

出口条件：**世界里有别人和物体**。

- 实体与玩家列表、玩家位置同步、容器/背包、聊天与命令
- 出口验收：能看到另一个玩家的移动、能收到并显示聊天

## M6 —— 模组与着色器包（未开始）

出口条件：**可扩展**。

- 原则 2：可卸载 `AssemblyLoadContext` 热加载/卸载（含 ALC 回收验证）
- 原则 11：着色器包接入点（渲染目标、阶段、采样契约）+ 失败回退
- 出口验收：热卸载后 ALC 被回收；样例包加载失败时回退内置管线不崩

## 待决项对里程碑的影响

| 待决项（AGENTS §5） | 影响 |
| --- | --- |
| 运行时形态（JIT/AOT/单文件） | 影响 M3 的分发形态与 AOT/Trim 分析器启用时机；不阻塞功能 |
| 性能目标数值 | 影响 M4 帧预算判定；建议 M4 开工前定稿 |
| 着色器包支持范围 | 决定 M6 的接入点接口形状 |
| 令牌安全存储 | M3 的启动器承接部分会触及（沿用当前仓库外缓存，生产前需换平台安全存储） |
