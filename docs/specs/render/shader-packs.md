# 着色器包契约（规格）

AGENTS.md 原则 11 要求渲染架构在**设计阶段**就为外部着色器包（Iris 风格）预留一等接入点：引擎能声明并允许包覆盖
渲染目标、阶段划分与顺序、采样与图像绑定、可用 uniform；新增 pass 只需包侧描述，不改引擎代码。

本文件只定义**契约形状与失败规则**，不定义 Iris 的具体文件格式（那是 `[待定]`，见 §6）。

## 1. 三层模型

| 层 | 谁定义 | 内容 |
| --- | --- | --- |
| 渲染目标 | 引擎 + 包可追加 | 名字、格式、尺寸策略（相对缩放或绝对像素）、用途 |
| 阶段（pass） | 包声明 | 名字、着色器程序、写哪个/哪些目标、读哪些目标、依赖的前序阶段 |
| 资源绑定 | 包声明 | 采样器（读目标/纹理）与 uniform 块，按阶段列出 |

引擎只提供**执行器**：按声明的顺序跑阶段、按声明绑资源、按声明校验。引擎**不得**内置 Iris 的语义分支。

## 2. 目标尺寸策略

| 策略 | 含义 |
| --- | --- |
| `Relative(token)` | 相对当前帧缓冲的比例，如 `0.5` 表示半分辨率；裁到至少 1 像素 |
| `Absolute(width, height)` | 固定像素，用于阴影图这类与屏幕无关的目标 |

缩放基准是**窗口帧缓冲的物理像素**，不是逻辑尺寸（与交换链配置一致，见 ADR-0004 的修订记录）。

## 3. 阶段执行规则

1. 阶段按其声明的**依赖**拓扑排序；同一层内保持包内书写顺序。
2. 检测到循环依赖、缺失依赖、同一目标被同一阶段写两次 → **加载失败**（见 §5），不得部分执行。
3. 包必须显式声明"最终输出阶段"：写回帧缓冲的那个阶段，缺省则整个包视为无效。
4. 引擎内置管线等价于一个只有一个阶段的内置包；因此"回退"= 用内置包替换外部包，走同一条执行器。

## 4. 采样与 uniform

- 采样声明：阶段 → (采样器名, 目标名, 过滤/寻址)。未在目标表里出现的目标名 → 加载失败。
- uniform 声明：阶段 → (uniform 名, 类型)。引擎提供**固定集合**（矩阵、相机、时间、目标尺寸）；
  包声明的未知 uniform → 加载失败，不做静默忽略（静默忽略会让包"看起来能用"但画面错）。

## 5. 失败与回退（原则 11 的硬要求）

任何一项校验失败都必须：

1. 给出**可诊断**信息：包名、阶段名、失败的字段与原因；
2. **不中断客户端**：回退到内置包，并在日志里写明"已回退"；
3. 失败信息不含资产内容与绝对路径（原则 3）。

不允许"部分生效"：半个包执行出来的画面比明确回退更难排查。

## 6. 与 Iris 的关系（待定部分）

- 目标版本、支持的特性子集、`.properties` 与阶段文件的实际映射规则：`[待定]`，落地时在此补章节并留 ADR。
- 明确不做：不追求 100% 复刻原版管线；对齐标准是**可观测产物**（阶段顺序、目标格式、最终像素）。
- 仓库内不得捆绑任何第三方包或其内容（原则 11）。

## 7. 与其它模块的关系

- 执行器属于 `Framework/Rendering`（唯一允许接触 WGPU 的层）。
- 阶段内部使用的世界几何来自 `Client`，但包只声明"读哪个目标"，不接触游戏对象。
- 测试只需断言声明模型与校验规则，不需要 GPU：契约层是纯数据 + 纯函数。

## 8. 真实样本与兼容指导（2026-10-30 补充）

- 结构解剖与实测数字：`docs/analysis/render/shader-pack-anatomy.md`（样本 ComplementaryUnbound r5.9.3，468 条目 / 1.2 MB）。
- 关键结论：包是**"维度 × 阶段"**两层结构（`program/<stage>.glsl` 共享翻译单元 + `worldN/<stage>.fsh|.vsh` 薄包装），
  **不是**全局单份；`shaders.properties` 280 行承载 profile `#define` 与选项界面布局。
- 已核对 Iris 官方文档（2026-10-30），本规格需补四条（**尚未写入正文，待所有者评审**）：
  ① `dimension.properties` 的维度映射与"未列出则回落基础目录"语义（并保留 `worldN` 遗留规则：存在任一 `worldN` 时基础目录不参与）；
  ② 官方完整程序顺序 `setup→begin→shadow→shadowcomp→prepare→gbuffers(不透明)→deferred→gbuffers(半透明)→composite*→final`；
  ③ `iris.features.required` / `optional` 的加载前检查（不支持则拒绝并列出缺失特性）；
  ④ 未识别阶段（DH/Voxy/colorwheel/Photonics）跳过并汇总日志。
- 来源：`shaders.properties` 官方参考（Programs 概览、shaders.properties 概览、dimension.properties 三页，链接见分析文档 §7）。
- 不支持特性与移植建议：`docs/specs/render/shader-pack-compatibility.md`。
