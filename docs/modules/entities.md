# Entities —— 实体系统根基

玩家不是特例，而是实体系统的一个成员。本模块先把**通用的实体移动与碰撞**做成一层，玩家、生物、掉落物、弹射物都复用它。

## 0. 这一版纠正了什么

此前把"玩家物理"直接写在 `Client/Player/PlayerBody`，那是**分层错误**：原版的移动与碰撞属于 `Entity` / `LivingEntity`，
玩家只提供"输入 → 意图"的映射与自身属性。`PlayerBody` 将并入本模块（`PlayerEntity`），客户端只保留输入与相机。

## 1. 职责范围

负责：

- `Aabb` 与 `EntityDimensions`：包围盒的构造与运算，尺寸/眼高按实体类型给出。
- `Entity`：位置、速度、尺寸、`Move(delta)` 的逐轴碰撞与碰撞标志（`OnGround` / `HorizontalCollision` / `VerticalCollision`）、
  `StepHeight` 自动上台阶。
- `LivingEntity`：`Travel(input)` —— 输入摩擦、方块摩擦、重力、水平/竖直阻力。
- `PlayerEntity`：玩家尺寸与属性、把 `MoveIntent` 映射为 `Travel` 的输入。
- 方块交互探针：固体性（`IsSolid`）与摩擦（`Friction`），由世界侧注入，实体本身不认识方块注册表。

明确不负责：渲染、输入采集、网络同步、AI、伤害、液体与攀爬等特殊移动（后续任务）。

## 2. 侧别归属

- 归属：**`Common`**。
- 判定依据：移动与碰撞是"客户端预测"与"服务端权威"**共用的同一算法**（原则 4、5）。放在 `Client` 会让服务端将来重复实现一遍，
  两边一旦不一致就是位置抖动与回弹；放在 `Server` 则客户端预测拿不到同一份实现。因此算法进 `Common`，
  `Client` 只做输入与表现，`Server` 将来只做权威推进与校验。

## 3. 原版事实（本模块据此实现）

| 事实 | 值 |
| --- | --- |
| 包围盒 | 以脚位为基准 `(x−w/2, y, z−w/2) … (x+w/2, y+h, z+w/2)` |
| 默认眼高 | `height × 0.85`；玩家单独指定（见 §5） |
| 基础重力 | `DEFAULT_BASE_GRAVITY = 0.08` |
| 输入摩擦 | `INPUT_FRICTION = 0.98` |
| 跳跃初速度 | `BASE_JUMP_POWER = 0.42` |
| 水平空气阻力 | `BASE_HORIZONTAL_AIR_DRAG = 0.91` |
| 竖直阻力 | `BASE_VERTICAL_AIR_DRAG = 0.98` |
| 方块摩擦 | 方块属性，默认 `0.6`（冰 0.98、粘液块 0.8 等另行给出） |

`Travel` 的真实顺序（`travelInAir` + `handleRelativeFrictionAndCalculateMovement`）：

```
块摩擦 f = onGround ? 方块摩擦 : 1.0
速度系数 = onGround
             ? (f > 0.6 ? 自身速度 × (0.21600002 / f³) : 自身速度)
             : 自身速度 × 0.1
moveRelative(速度系数, input)      // 按朝向把输入加到当前速度上
move(SELF, delta)                  // 逐轴碰撞，更新 onGround 与碰撞标志
dy -= 重力
水平 ← 水平 × (f × 0.91)
竖直 ← 竖直 × 0.98
```

**关键差异（对等效性至关重要）**：地面移动不是"速度直接等于输入"，而是"输入**累加**进速度，再由 `f × 0.91` 阻尼"。
它自然产生加速曲线与滑动距离；直接赋值会让手感与原版明显不同——起步太快、松键即停。`0.21600002` 就是 `0.6³`，
所以默认地面上的稳态速度约为 `速度系数 / (1 − 0.546) × 0.546` 的量级，而不是 `0.1`。

## 4. 移动顺序（`Entity.Move`）

1. 先 `Y`，再 `X`，再 `Z`（先竖直才能正确判定着地与摩擦来源方块）。
2. 某轴被挡：清该轴速度并把位置**钳到接触面**，置对应碰撞标志。
3. 单轴位移超过 `0.5` 格时拆分步进，避免隧穿。
4. 落地判定写入 `OnGround`，供下一步的摩擦计算使用。

## 5. 玩家专属

| 项 | 值 | 来源 |
| --- | --- | --- |
| 宽 / 高 | 0.6 / 1.8 | `EntityType.PLAYER` 的尺寸 |
| 眼高 | 1.62 | 玩家显式指定，非 `height × 0.85` |
| 行走速度属性 | 0.1 | 移动速度属性基础值 |
| 冲刺倍率 | 1.3 | 冲刺对速度属性的乘数 |
| 跳跃初速度 | 0.42 | `BASE_JUMP_POWER` |

`输入 → 意图`：`WASD` 映射为 `(forward, strafe)` 并归一到单位圆；`Space` 在着地时把竖直速度设为跳跃初速度。

## 6. 与原版对齐与偏离

对齐：AABB 基准点、默认眼高公式、重力/阻力/跳跃量级、摩擦影响的速度系数、逐轴碰撞与自动上台阶、地面累加式加速。

偏离（有意，本阶段）：不做潜行缩小碰撞盒、不做液体/攀爬/鞘翅、不做实体间挤压、不做属性修饰符系统（先写死基础值）。

## 7. 未完成与风险

- 移动常量与公式来自分析产物，**尚未用行为实验复核**（例如实际起跳高度、行走 10 格的耗时），需一次对照实验后收紧测试。
- 属性修饰符（`Attributes`）与实体类型注册表尚未建立；本阶段用常量表代替。
- 实体同步包（位置/速度广播）与预测回滚在 M5。
