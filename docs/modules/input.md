# Input —— 输入采集与语义映射

把平台输入（键盘、鼠标、焦点）收敛成**与平台无关的动作状态**，供相机与玩家逻辑消费。

## 1. 职责范围

负责：

- 采集按键按下/松开、鼠标位移与按键、鼠标捕获（相对位移）与释放、窗口焦点变化。
- 把物理键位映射为**动作**（`MoveForward`、`Jump`、`Sprint` 等），映射表可配置。
- 焦点丢失、捕获丢失时**清空所有按键状态**，避免"切出去再回来一直往前走"。

明确不负责：

- 不做相机数学（`Camera` 消费动作）、不做玩家物理（`Player` 消费方向输入）。
- 不实现 UI/文本输入（后续聊天需要单独一层）。
- 不直接调用平台 API：**平台实现只允许出现在 `Framework.Platform`**（原则 6）。

## 2. 侧别归属

- 归属：引擎层（`Framework`）采集 + `Client` 消费。
- 判定依据：输入是平台能力，必须经 `Framework.Platform` 抽象；"动作语义"属于客户端表现层。

## 3. 数据结构

| 类型 | 说明 | 线程 |
| --- | --- | --- |
| `KeyBindings` | 动作 → 物理键集合；默认 WASD / Space / ShiftLeft / Escape | 不可变，启动期构建 |
| `InputState` | 当前按下的动作集合 + 鼠标累计位移 + 滚轮 | 只在渲染线程读写 |
| `FrameInput` | 一帧的快照：移动向量（2D）、跳跃/潜行/冲刺布尔、视角增量 | 每帧创建一次结构体 |

- `InputState` 是**可变结构**，`FrameInput` 是**只读快照**；玩家与相机只看快照，避免"一帧内状态被你改我改"。
- 零分配：`FrameInput` 是 `readonly record struct`，每帧不产生堆分配。

## 4. 语义约定

- 移动向量：`(forward, strafe)`，范围各 −1..1；同时按下相反方向互相抵消。
- 视角增量：像素位移 × 灵敏度 → 角度增量；灵敏度默认 0.15°/px，可在 `KeyBindings` 外单独配置。
- 俯仰夹在 −90°..+90°，偏航不限（取模）。
- 正向为 −Z（原版相机朝向），偏航 0° 指向 −Z。

## 5. 焦点与捕获

| 事件 | 处理 |
| --- | --- |
| 焦点丢失 | 清空全部按键状态，释放鼠标捕获 |
| 捕获丢失（Esc） | 同上；再按一次重新捕获 |
| 窗口最小化 | 视为焦点丢失 |

## 6. 与原版对齐点与偏离

对齐：WASD 正交移动、Space 跳跃、Shift 潜行、鼠标相对位移控制视角、Esc 释放鼠标。

偏离（有意）：原版有大量可重绑定入口与手柄支持；本项目先做键盘鼠标最小集，绑定表留扩展位。

## 7. 未完成

- 手柄、触屏、IME 文本输入未实现。
- 绑定表尚未做用户可配置持久化（`[待定]`）。
