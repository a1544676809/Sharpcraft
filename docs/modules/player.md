# Player —— 玩家状态、移动与碰撞

让"人"在世界里动起来：速度、重力、跳跃、AABB 碰撞与台阶逻辑，量级对齐原版。

## 1. 职责范围

负责：

- 玩家 AABB（宽 0.6、高 1.8，眼高 1.62）、位置、速度、地面判定。
- 每 tick 的移动积分：重力、竖直阻力、地面摩擦、跳跃初速度。
- 与方块世界的碰撞解决（逐轴扫描 + 分轴回退）。
- 相机锚点：眼位 = 脚位 + 眼高。

明确不负责：

- 不做视角控制（`Input` 给增量，相机在 `Client` 侧组合）。
- 不做游泳、液体浮力、攀爬、潜行改变碰撞盒（后续任务）。
- 不做实体与玩家间碰撞。

## 2. 侧别归属

- 归属：`Client`（本阶段）。依据：单人集成服务端尚未落地前，玩家移动由客户端本地推进；
  接入集成服务端后，位移的权威判定会迁到 `Server` 侧，这里只保留预测与回滚接口位。

## 3. 常量与量级（行为规格，`[待实测确认]`）

| 量 | 值 | 说明 |
| --- | --- | --- |
| 重力加速度 | 0.08 blocks/tick² | 每 tick 先作用于竖直速度 |
| 竖直阻力 | 0.98 | 作用于竖直速度（下落/上升都适用） |
| 地面摩擦 | 0.6 系数（等价 0.91 保留） | 落地后水平速度衰减 |
| 行走速度 | 4.317 blocks/s（≈0.1 blocks/tick 起步） | 原版步行量级 |
| 冲刺速度 | 5.612 blocks/s | 原版冲刺量级 |
| 跳跃初速度 | 0.42 blocks/tick | 对应约 1.25 格跳跃高度 |
| 终端下落速度 | 3.92 blocks/tick | 竖直速度夹紧 |

这些数值来自公开行为观测，**尚未在本项目实测复核**，因此标记 `[待实测确认]`；落地测试只断言
"量级与关系"（跳跃高度在 1.2–1.3 格之间、冲刺快于行走、终端速度被夹紧），待有对照实验后再收紧。

## 4. 移动积分顺序（每 tick）

1. 读输入得到期望水平加速度方向，归一化后乘速度系数。
2. 竖直速度减去重力，乘竖直阻力；夹到终端速度。
3. 逐轴尝试位移：先 `Y`，再 `X`，再 `Z`；任一轴碰撞则该轴速度清零（竖直向下碰撞时置 `onGround`）。
4. 落地后应用地面摩擦到水平速度。

顺序固定，便于对照与复现；每步都要有测试。

## 5. 碰撞

- 与固体方块的 AABB 相交测试；只把"非空气且非液体"的方块当作固体（液体判定后续任务）。
- 单轴位移超过 0.5 格时拆分步进，避免高速穿模（本阶段先做拆分，隧穿测试守护）。

## 6. 与原版对齐与偏离

对齐：AABB 尺寸与眼高、重力/阻力/跳跃量级、逐轴碰撞语义、台阶不自动攀爬（原版 0.6 格以下不自动上台）。

偏离（有意）：不做潜行缩小碰撞盒、不做液体中的移动修正、不做实体挤压。
